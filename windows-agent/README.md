# Keyboard Layout Sync Agent

Маленький Windows tray-agent для синхронизации языка ОС с внутренним языком клавиатуры.

Агент раз в 300 мс смотрит язык активного окна Windows, но отправляет Raw HID-пакет только при смене языка или при ручном `Sync now`:

- английский язык отправляет в клавиатуру как `EN`
- русский язык отправляет в клавиатуру как `RU`

Если Windows не видит реального ввода пользователя дольше 5 секунд, агент ставит фоновую Raw HID-синхронизацию на паузу. Это сделано, чтобы агент не мог мешать скринсэйверу или отключению экрана. Ручной `Sync now` продолжает работать.

В прошивке это принимается через QMK Raw HID и обновляет внутреннее состояние `lang_shift` без отправки дополнительных клавиш в ОС.

Агент фильтрует Raw HID устройства и отправляет пакеты только ZSA/Moonlander-подобному устройству. Если в системе есть другая QMK-клавиатура с Raw HID, агент не должен отправлять ей команды.

## Сборка

На Windows запустить:

```powershell
.\windows-agent\KeyboardLayoutSyncAgent\build.ps1
```

Готовый файл появится здесь:

```text
windows-agent\KeyboardLayoutSyncAgent\bin\KeyboardLayoutSyncAgent.exe
```

Для сборки используется встроенный в Windows компилятор .NET Framework, отдельный .NET SDK не нужен.

## Запуск

Запустить `KeyboardLayoutSyncAgent.exe`. В трее появится иконка `Keyboard layout sync`.

Двойной клик по иконке делает принудительную синхронизацию. В меню иконки есть `Sync now`, `Refresh telemetry`, `Grid mode (Ctrl+Alt+G)`, `Diagnostics`, `Start with Windows` и `Exit`.

`Grid mode` открывает полноэкранную сетку для быстрого позиционирования курсора:

- `QWE` / `ASD` / `ZXC` выбирают сектор 3x3
- после трех выборов курсор прыгает в центр выбранной области
- `Enter` или `Space` прыгает в центр текущей области сразу
- `M` прыгает и делает левый клик
- `,` прыгает и делает средний клик
- `.` прыгает и делает правый клик
- `Backspace` сбрасывает выбор к полному экрану
- `Esc` закрывает сетку без перемещения курсора

Если в подсказке написано `Raw HID not found`, значит клавиатура еще не прошита версией с `RAW_ENABLE = yes`, либо Windows пока не увидела Raw HID endpoint.

## Диагностика

Пункт `Diagnostics` открывает живое окно состояния агента. В нем видно:

- текущий статус синхронизации
- текущий язык активного окна
- время последней Raw HID-отправки
- сколько миллисекунд Windows находится в простое
- включена ли idle-пауза
- сколько Raw HID устройств найдено
- последний ACK-результат
- telemetry из прошивки: внутренний язык, активный слой, состояние idle-подсветки, RGB, mouse-mode, счетчики зажатых клавиш
- последние строки лога

`Refresh telemetry` вручную запрашивает свежий снимок состояния прошивки. В окне Diagnostics кнопка `Refresh now` делает такой же разовый запрос, а `Live telemetry` включает опрос примерно раз в секунду только пока открыто это окно. При закрытии Diagnostics live-опрос выключается автоматически, чтобы не мешать Windows idle, скринсэйверу и отключению экрана.

В Diagnostics также есть `Copy` для копирования полного снимка состояния и `Open log folder` для быстрого перехода к файлу лога.

Лог пишется сюда:

```text
%LOCALAPPDATA%\KeyboardLayoutSyncAgent\agent.log
```

Когда лог достигает примерно 512 KiB, агент переносит его в `agent.log.old` и начинает новый файл.

## Статусы

Иконка показывает текущий язык:

- `EN` или `RU` на зеленом фоне: клавиатура подтвердила синхронизацию
- `EN` или `RU` на синем фоне: клавиатура временно проигнорировала пакет, потому что сама печатает спецсимвол
- желтый фон: пакет отправлен, но подтверждение не пришло, либо фоновая синхронизация поставлена на паузу из-за простоя Windows
- красный фон: Raw HID не найден или отправка не удалась

Если статус часто остается желтым после новой прошивки, значит Windows видит endpoint, но ответный пакет от прошивки не доходит до агента.
